## Gaps

1. Scope, Auto-houses (and criterion "Auto-house builders never come from idle villagers") - "over `NODE_REFS` order restricted to run refs" collides with the defined term `runRefs(order)`, which returns finite refs only (`FiniteNodeRef`), so farm and wood are not run refs. On main the fullest-node fallback scans all eight `GATHER_NODE_ORDER` nodes including farm and wood, with first-wins ties (`reduce` with `>`). An implementer reading "run refs" literally drops farm/wood from the fallback and changes M2 results. The design says "restricted to the run", not "run refs". Fix: say the candidates are `NODE_REFS` minus every `DepositRef` the order does not name (so farm and wood stay), ties go to the first in `NODE_REFS` order, and add a test where farm is the fullest node.
2. Scope, run-out machinery / node-depleted - how the engine knows which refs "ran out at this instant" is unspecified. Scope line 39 says the run-out "sets `depletedAt = now`" while line 40 says `recordRunOut` (SGS-037) sets it; `NodeStock` internals are free, so the engine has no API to set `depletedAt` itself. A ref that reaches 0 in the `drawDown` credit step, a ref that starts at 0, and a ref clamped within tolerance are three different detection paths. Fix: drop "set `depletedAt = now`" from the run-out bullet, and state that the engine keeps a per-instant list of refs where `isDepleted` is true and `recordRunOut` has not been called, moves their `gatherers` to `idle` first thing in `runInstant`, and calls `recordRunOut` for that list at the end of the instant (this also covers the t=0 case).
3. Scope / criteria, idle arrival at the run-out instant - the node-depleted `idleVillagers` is `idle[ref]` at the end of the instant, and an arrival at the same instant (events run after run-outs) lands in `idle[ref]` and also goes through `recordIdleArrival`. Both warnings count the same villagers, which contradicts "villagers already idle at the run-out instant are not counted" only if read loosely. Fix: state that this overlap is intended (node-depleted counts idle at end of instant including same-instant arrivals; idle-arrival counts every arrival at a depleted ref), or exclude it, and add one test for the chosen behavior.
