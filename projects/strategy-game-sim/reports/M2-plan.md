2. **Recharts pin in design/M2.md is still 2.15.4.** C is `blocked-on` the designer's SGS-012 On-merge update to
   3.10.1 with the chart selectors re-verified. If 3.x changes a selector or the SSR note (`ResponsiveContainer`
   empty div on the server), C and J follow the updated design.

   owner pick, J chooses a published English opener (e.g. a feudal or fast-castle build) that uses only v1 steps
   (no Council Hall, Network of Castles or Abbey effects, which are "later") and records its URL in `source`.
   Owner: name a build if you want a specific one.
4. **Page title and link text.** `acceptance/landing.spec.ts` asserts the app page `h1` equals the landing link
   text; the design names neither. J proposes "AoE4 Build Order Simulator" unless the owner names another.
5. **Unit tests for component helpers vs. the Vitest include.** design/M2.md asks for unit tests of `toChartRows`
   (in `line-chart.tsx`) and the result-to-series mapping, but `vitest.config.ts` only includes
   `utils/**/*.test.ts` and `lib/**/*.test.ts`. Not an owner decision: C extends `include` to
   `components/**/*.test.ts` or moves the pure helpers to a `.ts` sibling; J follows C's choice.
6. **Research before H.** F lands before H; F must state whether a `research` step is rejected or stays
   `waiting` until H wires the handler. Ticket-level decision; noted so the F and H tickets agree.
