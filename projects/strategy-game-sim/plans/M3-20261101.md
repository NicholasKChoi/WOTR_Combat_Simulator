# Plan: M3 (2026-11-01)

Base: `origin/main` f078c11. Design: `design/M3.md` (approved, no open owner decisions). Backlog input:
`reports/M3-backlog-chosen.md` (every chosen item is placed below; the REPO.md review-checklist item is dropped
because it is already done).

Graph shape: four independent roots (A, B, R, S; A is the first engine ticket the design asks for), a wave after A
(C, I), a wide wave after C (D, G, H), and the longest chain A -> C -> D -> E -> F -> L -> U (7 levels). The chain cannot be
cut further without an outline defining a contract it cannot yet honor: the `Trigger` union cannot widen before the
engine handles the new kinds (`simulate.ts:169` switch, `validate.ts:257` treats any non-`time` kind as
`villagers`), so the paste grammar (F) waits for the engine (E).

Rule for every outline that changes a response or request shape: `docs/api/openapi.json` changes in the same diff.
`SimulationResult`, `StepTiming`, `BuildOrderNote` and `SimulateError` have `additionalProperties: false` and full
`required` lists, so `acceptance/aoe4-simulate-api-contract.spec.ts` (ajv) fails on any unmatched field. Each
outline also updates the `docs/aoe4-build-order.md` section for the behavior it adds; T audits the whole.

## Spec gaps

None that block planning. Every `code` criterion lands in a named file. Two items need the owner's attention:

- **Lint gate on main**: there is no CI workflow (`.github/workflows` absent) and no `lint` script in
  `package.json`. "jscpd lint passing on main" (M3.13) is enforced only through REPO.md `commands.lint` run by the
  factory gates. If the owner wants it enforced elsewhere (Vercel build, a GitHub Action), that is outside M3's
  design.
- **Node version for gates**: `package.json` declares `engines.node: 24.x` and REPO.md says acceptance needs Node 24,
  but the shell default is v22.17.0. `lint:dup` via `npx jscpd` and the Playwright flow (U) should run under Node 24.
