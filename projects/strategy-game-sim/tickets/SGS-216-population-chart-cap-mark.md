## Context

No chart draws population today, and the run's `populationCapReachedAt` shows only as a Key results row. This ticket adds a fifth chart, Population, that draws `spawnedPopulation`, and one page-side vertical mark on it at `populationCapReachedAt`, labelled `Population cap m:ss` (design OD2 = B: no marker kind, no Markers-control entry, no API change). Branch: `sgs-216-population-chart-cap-mark`. The sibling ticket SGS-215 (engine, docs of the engine and format Outputs, OpenAPI descriptions) touches disjoint files; the Playwright spec SGS-217 depends on this ticket and reads these names: test ids `chart-population` and `chart-time-mark` (attributes `data-at`, `data-label`), label text `Population cap m:ss`, and the exports below.

## Scope

Branch `sgs-216-population-chart-cap-mark`. Specify against origin/main's `line-chart.tsx` (zoom window `shown`, the `inWindow` rule, the `drawn` and `visible` marker lists, `markerView`), not the design's revision 1 description.

Code (names are the design's contracts; use them exactly):
- `components/apps/aoe4-build-order/chart-markers.ts` (the one home of marker rules, D15): add `ChartTimeMark` (`{ at: number; label: string }`), `TIME_MARK_COLOR` (`#a52a2a`), `timeMarkLabel(mark)` (the mark's label, a space, and `formatMinSec(at)`, the same m:ss as `markerLabel`) and `timeMarkLabelPosition(at, end, plotWidth, labelWidth, origin = 0)` returning `'insideBottomLeft'` (text right of the line) or `'insideBottomRight'`, by the `placeMarkers` rule: with `a = at - origin`, left when `a + labelWidth * end / plotWidth <= end`, else right. `end` is the shown span in seconds and `origin` the time at its left edge.
- `components/apps/aoe4-build-order/result-series.ts`: add `populationSeries(run)` (one series, key `population`, name `Population`, values `run.spawnedPopulation`) and `populationCapMark(run)` (`null` when `populationCapReachedAt` is `null`, else `{ at: populationCapReachedAt, label: 'Population cap' }`; `at` 0 is a reached cap).
- `components/apps/aoe4-build-order/line-chart.tsx`: `SeriesChartProps` gains optional `timeMark?: ChartTimeMark | null` (default null draws nothing). A non-null mark is drawn only when unzoomed, or zoomed with `shown.from <= at <= shown.to` (the `inWindow` rule; D16). Put that decision in an exported pure function beside `inWindow` and `bandIn` so a unit test can reach it (name chosen by the implementer and listed in the report). When drawn, render one `ReferenceLine` after the `visible` marker lines: `x={at}`, `stroke={TIME_MARK_COLOR}`, `strokeWidth={2}`, `data-testid="chart-time-mark"`, `data-label`, `data-at`, label `timeMarkLabel(mark)`, fill `TIME_MARK_COLOR`, the marker label font size, position from `timeMarkLabelPosition(at, shown.to - shown.from, plotWidth, width, shown.from)` with the label's measured width or `estimateLabelWidth` before measuring (measure or estimate only: left to the implementer). The mark ignores `markerView` (D17), does not enter `placeMarkers`, the label rows or `data-label-rows`, and is not focusable. `use-chart-zoom.ts` and `chart-zoom.ts` stay unchanged: a pointer-down on the mark's bottom label starts a zoom selection like anywhere in the grid (D18).
- `components/apps/aoe4-build-order/chart-layout.ts`: add `'chart-population'` as the last of `RESULT_CHART_IDS` (so the default order ends with it, and `normalizeChartLayout` appends it to a stored layout that lacks it).
- `components/apps/aoe4-build-order/results.tsx`: the `charts` record type gains optional `timeMark?: (run: SimulationResult) => ChartTimeMark | null`; add `'chart-population'` with title `Population`, y label `Population`, `series: populationSeries`, `timeMark: populationCapMark`, no `headerControls`; `SeriesChart` gets `timeMark={chart.timeMark?.(result) ?? null}` (the current run only; the pinned run's cap is never marked, D9). The other four charts get no mark. The pinned run's `populationSeries` draws through the existing pinned-series path as the dashed `pinned:population` line.

## Acceptance criteria

- [ ] `populationSeries` returns exactly one series, key `population`, name `Population`, whose values are the run's `spawnedPopulation` (a test uses values that differ from every other series the module derives, so a wrong source fails)
- [ ] `populationCapMark` returns `null` when `populationCapReachedAt` is `null`, and `{ at, label: 'Population cap' }` with the run's value when reached, including `at` 0 (a test fails if a falsy `at` is treated as not reached)
- [ ] `timeMarkLabel` gives the label, a space and the same m:ss `markerLabel` gives for that `at` (a test compares it with `markerLabel` for a marker of the same `at`)
- [ ] `timeMarkLabelPosition` puts the text right of the line (`insideBottomLeft`) when it fits before the plot end, including `at` 0 and a label that ends exactly at the end, and left (`insideBottomRight`) when it would pass the end; a case with a non-zero `origin` gives a different answer than the same `at` with `origin` 0, and a test fails if `origin` is ignored or the boundary is made strict
